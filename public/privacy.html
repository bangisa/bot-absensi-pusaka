🤖 Bot Absensi Pusaka Kembali ke Login

Privasi

Kebijakan Privasi

Terakhir diperbarui: 2 Oktober 2026

1. Ruang Lingkup

Kebijakan ini menjelaskan bagaimana Bot Absensi Pusaka memproses data yang diperlukan untuk menjalankan fungsi administrasi, penjadwalan, dan otomasi presensi.

2. Data yang Diproses

Aplikasi dapat memproses nickname/nama samaran, username akun Pusaka, password akun Pusaka, koordinat yang dikonfigurasi, cookie/session Pusaka, jadwal presensi, status hasil presensi, serta log operasional dan audit.

3. Tujuan Penggunaan

Data digunakan hanya untuk menjalankan fungsi aplikasi, termasuk login ke Pusaka, menjalankan workflow presensi yang telah dikonfigurasi, membuat jadwal, melakukan retry, menampilkan status operasional, pencatatan log, diagnosis, dan pemulihan sistem.

4. Perlindungan Credential

Username dan password Pusaka disimpan dalam keadaan terenkripsi. Credential hanya didekripsi sementara di memory ketika dibutuhkan oleh workflow login. Password tidak ditampilkan kembali melalui halaman Users atau API publik aplikasi.

5. Log dan Audit

Aplikasi menerapkan masking dan redaction untuk mengurangi kemungkinan password, token, cookie, secret, dan credential terenkripsi tercatat di log. Log presensi dan audit tetap dapat memuat nickname, jenis aktivitas, status, waktu, dan pesan operasional yang diperlukan untuk administrasi.

6. Penyimpanan dan Backup

Data utama disimpan pada database SQLite milik instalasi aplikasi. Backup database mingguan dapat dibuat secara otomatis sesuai konfigurasi retention. File kunci credential disimpan terpisah dari backup database dan harus diamankan oleh administrator.

7. Layanan Eksternal

Credential Pusaka digunakan untuk berinteraksi dengan layanan Pusaka. Aplikasi juga dapat mengakses provider kalender hari libur untuk memperoleh informasi tanggal libur; credential pengguna tidak dikirim ke provider kalender tersebut.

8. Akses Administrator

Dashboard administratif dilindungi dengan session admin. Administrator bertanggung jawab menjaga password admin, file .env, database, file kunci credential, server, dan akses sistem operasi tempat aplikasi berjalan.

9. Penghapusan Data

Data user aktif dapat dihapus melalui halaman Users. Log dan backup mengikuti kebijakan retention aplikasi; administrator dapat menghapus arsip yang tidak lagi diperlukan sesuai kebutuhan operasional.

10. Perubahan Kebijakan

Kebijakan ini dapat diperbarui ketika cara kerja, fitur, atau mekanisme penyimpanan aplikasi berubah. Tanggal pembaruan akan dicantumkan pada halaman ini.
