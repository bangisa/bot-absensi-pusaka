Lupa Password Admin?

Demi keamanan, reset password tidak dapat dilakukan dari internet atau browser. Reset hanya dapat dilakukan langsung dari direktori aplikasi di server.

  1. Hentikan aplikasi.
  2. Buka terminal pada root project.
  3. Jalankan npm run admin:reset.
  4. Masukkan password baru dan konfirmasinya.
  5. Jalankan aplikasi kembali.
Tidak ada link reset melalui email dan tidak ada endpoint publik untuk mengganti password admin.
